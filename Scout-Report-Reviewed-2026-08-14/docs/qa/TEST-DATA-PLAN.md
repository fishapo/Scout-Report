# Test Data Plan
Use a clearly synthetic dataset in non-production environments.

Minimum dataset:
- 4 users: Scout, Inter-Farm Supervisor, HOD, Admin
- 3 farms
- 3 crop types with multiple varieties
- at least 3 pest observations
- at least 3 disease observations
- at least 2 other-condition observations
- reports spanning at least 3 months
- reports in Draft, Awaiting Supervisor, Awaiting HOD, Awaiting Admin and Approved states

Use the dataset to reconcile dashboard totals, crop/farm charts, monthly trends and workflow distribution.
