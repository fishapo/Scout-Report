# Release Notes — Analytics & User Management Rebase

### Added
- Shared analytics dashboard for every application role.
- Automatic KPI cards, crop/farm bar charts, monthly trend graph, workflow pie chart and recent-report table.
- Browser print layout.
- Dependency-free XLSX export/import service.
- Admin create/delete users and role editing.
- All workflow roles can create new reports without skipping verification.

### Preserved
- Multi-stage report verification workflow.
- Existing authentication/session model.
- Existing admin reference CRUD.
- Existing report ownership/security tests.

- Dashboard auto-refreshes every 60 seconds and adds analytics indexes for PostgreSQL.
