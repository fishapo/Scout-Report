# Support Handover Checklist

## Application
- [ ] Release candidate identifier recorded.
- [ ] Node.js/npm versions recorded.
- [ ] Environment variables configured from secure storage.
- [ ] `/health` and `/api/health` monitored.
- [ ] Admin and Scout roles verified.

## Database
- [ ] PostgreSQL version recorded.
- [ ] Migration applied.
- [ ] Backup schedule active.
- [ ] Restore procedure tested.

## Operations
- [ ] Monitoring dashboard owner assigned.
- [ ] Alert recipients configured.
- [ ] Incident escalation contacts assigned.
- [ ] Rollback owner assigned.
- [ ] Maintenance window documented.

## Handover evidence
Keep the final test report, deployment identifier, backup verification and incident runbook with the release record.
