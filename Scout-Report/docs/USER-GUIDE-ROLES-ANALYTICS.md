# User Guide

## All roles

After login, use **Analytics Dashboard** to view automatic totals, charts, workflow pipeline, recent reports and printable tables. Use **New Report** to open the Scout Report form.

### Excel
- **Export Excel** downloads a real `.xlsx` workbook.
- **Import Excel** accepts the same columns produced by export.
- Import does not approve or skip workflow verification.

## Workflow

`Scout → Inter-Farm Supervisor → Head of Department → Administrator → Approved`

Each forward transition requires verification by the receiving role. Rejection returns the report to the previous stage.

## Administrator

The Administrator can open **User & Role Management** to:
- add users;
- change a user's application role;
- delete users;
- retain protection against deleting the last administrator or the currently logged-in administrator.

## Printing

Use **Print** on the analytics dashboard. The page uses print-specific CSS to hide navigation controls and produce a clean report.
