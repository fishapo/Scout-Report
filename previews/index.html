API Endpoints

Run npm start to start the API server on port 3000.

GET /farms - Retrieve available farms
GET /crop-types - List all crop types
GET /crop-types/:id/varieties - Get varieties for a crop type
GET /pests - List common pests
GET /diseases - List common diseases
GET /scout-reports - List scout reports (with filters)
GET /scout-reports/stats - Dashboard statistics
GET /scout-reports/:id - Get a single report
POST /scout-reports - Create new scout report
POST /scout-reports/:id/pest-observations - Add pest observation
POST /scout-reports/:id/disease-observations - Add disease observation
DELETE /scout-reports/:id - Delete a report
